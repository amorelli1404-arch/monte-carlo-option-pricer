## Executive Summary
This project implements a vectorized Monte Carlo framework for pricing European options under the risk-neutral measure. To minimize variance and guarantee empirical convergence, the engine uses **Antithetic Variates** applied directly to exact discrete paths of Geometric Brownian Motion (GBM). The numerical results are benchmarked against closed-form analytical solutions derived from the Black-Scholes-Merton model, paired with a Finite Element Analysis (FEA) style 3D surface map visualization.

## Mathematical Foundations

### 1. Stochastic Differential Equation (SDE)
Under the risk-neutral measure $\mathbb{Q}$, underlying asset price dynamics follow Geometric Brownian Motion:

$$dS_t = r S_t dt + \sigma S_t dW_t$$

Where:
* $S_t$: Asset price at time $t$
* $r$: Risk-free interest rate
* $\sigma$: Volatility of the underlying asset
* $dW_t$: Standard Brownian motion process increment ($dW_t \sim \mathcal{N}(0, dt)$)

### 2. Exact Analytical Solution via Ito's Lemma
Applying Ito's Lemma to $f(S_t) = \ln(S_t)$ yields the exact discrete path generator for terminal asset price $S_T$:

$$S_T = S_0 \exp\left( \left(r - \frac{1}{2}\sigma^2\right)T + \sigma \sqrt{T} Z \right), \quad Z \sim \mathcal{N}(0, 1)$$

### 3. Option Valuation & Variance Reduction
The risk-neutral European option value $V_0$ is evaluated by discounting expected terminal payoffs:

$$V_0 = e^{-rT} \mathbb{E}^\mathbb{Q} \left[ \max( \eta (S_T - K), 0 ) \right]$$

where $\eta = 1$ for a Call option and $\eta = -1$ for a Put option.

**Antithetic Variates** is implemented by pairing random draws $(Z, -Z)$, reducing estimator sample variance without requiring additional random generation overhead.
